[1] T-1 调查：构建报告属性已废弃
--------------------------------------------------
现象：gradle.properties 配的是
        kotlin.build.report.dir=D:/EinkLegado/build/reports/kotlin
      但构建实际输出到 build/reports/kotlin-build，两者不一致。

实测：gradlew help -Pkotlin.build.report.dir=build/reports/TESTPROBE
输出：
  w: Deprecated Gradle Property 'kotlin.build.report.dir' Used
  The `kotlin.build.report.dir` deprecated property is used in your build.
  Kotlin build report is written to file:///D:/EinkLegado/build/reports/kotlin-build/...

结论：该属性已被 Kotlin 2.3.10 废弃，赋值被忽略。原配置既写死绝对路径，
      又完全不生效，且每次构建都刷一条废弃警告。
      因此正确处理不是「改成相对路径」，而是**删除**。

修复：gradle.properties 删除 kotlin.build.report.dir 一行，保留
      kotlin.build.report.output=file，并加注释说明为何不要再加回来。

验证：gradlew help → 废弃警告消失，报告仍正常生成。
      BUILD SUCCESSFUL

[3] T-6 核实：网格书架确已死代码
--------------------------------------------------
用户提示「网格书架昨天就删掉了」，核实结果：属实，但删的是入口不是代码。

证据：app/src/main/java/io/legado/app/help/config/AppConfig.kt:239-244
        // 墨水屏专属：固定为列表视图（0），不再提供紧凑列表与网格
        var bookshelfLayout: Int
            get() = 0
            set(value) { appCtx.putPrefInt(PreferKey.bookshelfLayout, 0) }

       getter 恒为 0，因此下列 `bookshelfLayout >= 2` 分支永不可达：
         ui/main/bookshelf/style1/books/BooksFragment.kt:74,105,149,192,282,296
         ui/main/bookshelf/style2/BookshelfFragment2.kt:63,93,112,148,213
         ui/main/bookshelf/style2/BooksAdapterList.kt:28

结论：T-6 原描述「网格分页未真机验证」不准确——网格路径根本无法触发，
      不是「未验证」而是「不可达」。真机验证无意义。
      改为待清理项（现 TODO T-6）。
