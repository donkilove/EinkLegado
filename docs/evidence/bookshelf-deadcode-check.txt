[1] 调查：不可达路径的根因
--------------------------------------------------
app/src/main/java/io/legado/app/help/config/AppConfig.kt
  :233-237  var bookGroupStyle: Int   get() = 0   // 固定标签分组
  :240-244  var bookshelfLayout: Int  get() = 0   // 固定列表视图

由这两个恒为 0 的 getter 推导出的不可达路径：
  MainActivity.kt:491   if (bookGroupStyle == 1) idBookshelf2 else idBookshelf1
                        → idBookshelf2 永不命中，style2 整包不可达
  BooksFragment.kt:74   when (bookshelfLayout) { 1 -> List2; else -> Grid }
                        → 后两个分支永不命中
  BooksFragment.kt      6 处 bookshelfLayout >= 2 判断恒为 false
  BookshelfFragment2.kt 5 处 bookshelfLayout >= 2 判断恒为 false

结论：T-6 原描述「网格分页未真机验证」不准确，实为「路径不可达」。
