== webdav-sync-v3 追加四：自动上传与按需下载实测（补齐最后两项） ==
环境：Windows 11，项目 D:\EinkLegado
日期：2026-11-26
JDK：Microsoft OpenJDK 17.0.21.1，GRADLE_USER_HOME=D:\gradle-home
设备：模拟器 eink_test（android-35）
服务端：本机 build/webdav_test_server.py，端口 8080，账号 test/test

此前这两项一直标为「未实测：缺可用 WebDAV 服务器」。
本轮用本机服务器 + 一本自制测试书全部跑通。

--------------------------------------------------
[1] 测试书
--------------------------------------------------
自写 build/testbook.txt（348 字节，三章），推到 /sdcard/Download/。
通过书架 → 溢出菜单 → Import books → Manual Input 输入 /sdcard/Download
→ 勾选 testbook.txt → Add to Bookshelf 导入。

（Manual Input 只接受目录，不接受文件路径——它是「书籍目录」设置项，
 不是文件选择器。第一次误填文件路径被拒，属预期行为。）

--------------------------------------------------
[2] 自动上传本地书：通过
--------------------------------------------------
前置：autoUploadLocalBook=true，WebDAV 已配置。

导入后立即检查：
  服务端出现 legado/books/testbook.txt
  本地 books 表该行 origin 变为
    webDav::http://10.0.2.2:8080/legado/books/testbook.txt
  即 LocalBook.autoUploadIfNeeded → RemoteBookWebDav.upload 生效，
  书从「本地书」转为「WebDAV 书」。
  → webdav-sync-v3-autoupload.png

--------------------------------------------------
[3] 按需下载：通过
--------------------------------------------------
删除本地文件 /sdcard/Download/testbook.txt，清空 book_cache，
点开书架上的 testbook。

服务端日志出现：GET /legado/books/testbook.txt 200
本地文件重新出现，正文正常显示（三章内容完整）。
  → webdav-sync-v3-ondemand.png

--------------------------------------------------
[4] 关闭按需下载时的提示：通过
--------------------------------------------------
置 autoDownloadWebDavBook=false，再次删除本地文件，点开同一本书。

屏幕显示：
  打开本地书籍出错：On-demand download is off, and this book has no local file
服务端日志**没有**出现 GET /legado/books/testbook.txt。
即开关关闭时确实不发请求，且提示说明了真实原因（设置问题，不是数据丢失）。
  → webdav-sync-v3-ondemand-off.png

--------------------------------------------------
[5] 排错记录（供后续参考）
--------------------------------------------------
第一次测「关闭按需下载」时书仍能打开，误以为开关失效。实际原因：
  - 删错了路径（删的是 files/testbook.txt，真实路径是 /sdcard/Download/testbook.txt）
  - 且 chapters 表里已有章节缓存，正文从缓存读出，不需要读文件
删对路径后现象符合预期。
